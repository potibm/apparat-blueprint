# AGENTS.md — Apparat Blueprint

Compact cheat-sheet for OpenCode. Omit anything an agent could guess from filenames.

---

## Repo layout

- **Go backend**: `backend/` (module `github.com/potibm/apparat-blueprint`)
- **React frontend**: `frontend/` (Vite + React Admin + Tailwind v4 + Flowbite React)
- **Infra**: `docker-compose.yaml` (Traefik, Dex, OpenObserve, OTel collector, Redis)
- **Root `go.work`**: points only to `./backend`. Run Go commands from `backend/`.

**This is a template repository: platform only, no business logic.** There is exactly one frontend
app (`@admin`, mounted at the root path) with zero `<Resource>`s, and the backend exposes only
`GET /api/config`. `CONCEPT.md` documents the architecture and the extension points — it does _not_
describe a data model. Do not assume models, repositories or routes exist — check first.

Path aliases (vite + tsconfig): `@core`, `@admin`.

## Everyday commands (mostly via `mise`)

Install mise tools once: `mise install`  
Install project deps: `mise run deps:install`  
Full setup (deps + infra): `mise run setup`  
Infra only: `mise run infra:prepare` (certs/DNS, needs sudo) then `mise run infra:up`  
Dev (hot-reload both): `overmind s --timeout 10` (uses Procfile)

Backend only: `mise run be:dev` (Air, port **3401**)  
Frontend only: `mise run fe:dev` (Vite, port **3400**, proxies `/api` → :3401)

Test everything: `mise run test`  
Backend tests: `mise run be:test`  
Frontend tests: `mise run fe:test`  
Coverage reports: `mise run be:test:cov`, `mise run fe:test:cov`

Lint everything: `mise run lint`  
Lint with auto-fix: `mise run lint --fix`

Full build into `./dist`: `mise run build`  
Docker image: `mise run docker:build` (buildx builder `apparat-blueprint-builder`)

## Critical gotchas

### `cmd/assets` must exist before any Go build

`backend/cmd/serve.go` embeds `//go:embed assets`. If the directory is missing, **compilation fails**.

- `mise run be:setup` creates it (plus a dummy `index.html`) and creates the `data/` subdirectories.
- `mise run be:lint` also creates a dummy file for this reason.
- `mise run be:test` depends on `be:setup`, so tests via `mise` are safe; running `go test ./...` directly without `be:setup` first will fail.
- Dockerfile copies the real frontend build into `backend/cmd/assets`.

### Do not run `go mod tidy`

`backend/internal/app/deps/deps.go` (build tag `deps`) blank-imports `aws-sdk-go-v2/service/sesv2`,
`google/uuid` and `gofakeit/v7` so they are downloaded and kept in `go.sum` for **offline work**
even though no product code uses them yet. `go mod tidy` respects build tags, so it keeps them as
long as the file exists — but it _would_ drop every other currently unused dependency in `go.mod`.
App-specific deps (Markdown rendering/sanitising, feed parsing, S3 client, …) are intentionally
_not_ pinned; add them to your own project when needed.
Treat `mise run be:deps:update` as a deliberate, network-requiring act, not a routine step.

### Config loading order

1. `backend/config/config.yaml` (committed defaults)
2. `backend/config/config.local.yaml` (gitignored overrides)
3. `.env` (loaded by `godotenv`)
4. Environment variables (`APP_LOG_LEVEL` maps to `app.log_level`)
5. CLI flags (`--log-level`, `--port`, etc.)

Use `config/config.local.yaml` for local secrets; do not edit `config.yaml`.
Generate a fresh one with `go run . config create`.

### Frontend dev proxy

Vite proxies `/api` to `http://127.0.0.1:3401`. The backend dev server (`air`) runs on **3401**,
not 3400. Dev traffic is plain HTTP on `localhost:3400`; HTTPS + `*.apparat-blueprint.test` comes from
Traefik and mkcert.

### Frontend tests need `--no-webstorage`

The `fe:test` task sets `NODE_OPTIONS="--no-webstorage"`. Running `npm run test` directly may behave differently.

### Tailwind v4 is really wired — keep it that way

Three pieces must stay in sync or styles silently vanish (the generated CSS drops to ~1 byte):

1. `tailwindcss` + `@tailwindcss/vite` in `frontend/package.json`
2. `tailwindcss()` and `flowbiteReact()` in the `plugins` array of `frontend/vite.config.ts`
3. `@import "tailwindcss"` in `frontend/src/index.css`

`frontend/.flowbite-react/class-list.json` is generated by the Flowbite plugin and gitignored.

## Where to add business logic

The extension points are deliberately the only places that need touching:

- **Models/migrations**: `allModels` in `backend/internal/app/store/gorm/store.go` — it feeds both
  `AutoMigrate` and `PurgeAll`. Add GORM models embedding `GormModel` + `AuditModel` there.
- **Repository interfaces**: `backend/internal/app/repository/` (currently empty — create it).
- **Domain types**: `backend/internal/app/domain/`.
- **API endpoints**: implement `RegisterAdminRoutes` in `hub.Config` (see
  `backend/internal/app/hub/hub.go`); routes registered on the returned group inherit the OIDC
  middleware. `GET /api/config` is public by design.
- **Admin resources**: `src/apps/admin/resources/<name>/` — a folder with an `index.ts` default
  export `{ name, list, edit, ... }` plus the list/create/edit/input components and a types file.
  Register it with `<Resource {...thing} />` in `src/apps/admin/Admin.tsx`.
- **List endpoints** must speak the React Admin protocol: `?_start&_end&_sort&_order` in, and an
  `X-Total-Count` response header for the `ra-data-json-server` provider to paginate.
- **Audit columns** are filled from the request context key `domain.UserIDKey`, which
  `middleware.AuthMiddleware` sets from the OIDC `sub`.
- Errors should use the RFC 7807 helpers in `backend/internal/app/hub/errors.go`.

## Lint / typecheck / test pipeline

CI order: `deps:install` → `lint` → `test` → `docker:build` → SonarQube.

- **Backend lint**: `golangci-lint` (config in `backend/.golangci.yaml`). Uses `gofumpt` + `golines` (120 cols).
- **Frontend lint**: ESLint + Prettier + `tsc --noEmit` + `dotenv-linter`.
- **Repo lint**: Prettier over `*`, `.github`, and `backend/**/*.{json,yml,yaml,md}`.
- **Shell lint**: `shellcheck` over `.mise/tasks`.
- **Workflow lint**: `actionlint` over `.github/workflows`.

## Infra (local)

`mise run infra:up` starts:

- Traefik: http://localhost:80 (HTTP→HTTPS redirect), https://localhost:443, dashboard: http://localhost:8080
- OpenObserve UI: https://observe.apparat-blueprint.test (admin@example.com / password123)
- OTel gRPC: localhost:3417, OTel HTTP: localhost:3418
- Redis: localhost:3451, RedisInsight: https://redis.apparat-blueprint.test
- Dex OIDC: https://dex.apparat-blueprint.test

All of the above credentials are **well-known development defaults hard-coded in
`docker-compose.yaml` / `infra/dex-config.yaml`, not secrets**. Do not treat them as safe for any
non-local environment, and do not commit real credentials next to them.

Backend dev (`air`) defaults to `--otel-endpoint=localhost:3417`.

To run several projects side by side on one machine, connect to a shared Traefik via the
gitignored `docker-compose.override.yaml` — see [doc/global-traefik.md](doc/global-traefik.md).

## Style notes

- Go: `slog` only (depguard blocks `logrus`). Use snake_case for slog keys.
- Go: avoid `math/rand` (use `math/rand/v2`).
- Go: config secrets go into `config.local.yaml`, never into `config.yaml`.
- TS: `no-console` and `no-alert` are errors. `_` prefix ignores unused vars.
- TS: new `.js` files are forbidden by ESLint (use `.ts`/`.tsx`).
- TS: `@mui/material` and `@mui/icons-material` are not direct dependencies; they resolve as
  transitive deps of react-admin. Adding an import of them works but is undeclared.
